# Decisions log

Smaller choices that don't warrant an ADR. Newest first.

## 2026-11-16

- **alejandra, not nixfmt.** Matches every other Qezta and DivitMittal repository.
- **mdformat instead of markdownlint-cli2/prettier.** Same reason; mdformat both formats and checks, so a second Markdown linter would only conflict with it.
- **Exporters return `{ format; value; }` data** rather than derivations, keeping the core free of `pkgs` (see ADR 0003). JSON is pretty-printed with `jq -S` during materialization for stable, readable diffs.
- **`company.asOf` added.** Pure evaluation has no clock, so overdue-style checks need an explicit reference date. Leaving it null skips them.
- **`specVersion` in spec.json** (fixed at `0.1.0`), so consumers can detect format changes.
- **"Current" means every status except `former`.** Current people's role references must resolve and GitHub-mapped roles require a `githubUser`; former people may reference deleted roles.
- **`systems.<id>.description` added** to the draft data model: Backstage and docs need it.
- **`systems.<id>.domain` is optional**, since small companies may not use domains for everything.
- **CODEOWNERS default is a real option default** (`[{ pattern = "*"; owners = [owner]; }]`), so spec.json shows the resolved rules.
- **Negative tests read `config.assertions`** instead of catching throws: `builtins.tryEval` drops the message, so only type errors (which never reach assertions) are tested by failure alone.
- **Exporter toggles use camelCase** (`company.exports.specJson.enable`), the usual Nix option style.
- **x86_64-darwin kept** by pinning `nix-systems/default` to the last revision that lists it, as the other Qezta repos do.
- **Actions pinned by SHA** in `flake/actions/common.nix`, with the release tag beside each pin. Workflows are generated by actions.nix like the other repos.
- **Pre-commit treefmt hook disabled**, matching other repos; formatting is enforced by the `treefmt` flake check instead.
